# ServiceCard

Service cards led by the grain mesh texture, which is locked for the five service pages (5 Nov 2026). Each service uses its own variation in its V1 colour family (Imagery asset group, `service-mesh-<key>.webp`). On hover the image eases in, the V1 conic sweep traces the card edge and the icon tile tilts.

Markup: `.xd-card.xd-card--interactive.xd-service.xd-service--art.xd-svc-<key>` containing `.xd-service__art > img` (decorative, empty `alt`), an `.xd-iconbox` with the service icon, an `.xd-h3`, an `.xd-body` line and `.xd-service__more`. Keys and V1 families: `reengineer` (Transform), `intel` (Discover), `cloud` (Enable), `govern` (Govern), `innovate` (blush to apricot). Service names follow the capability statement v1.0; check copy against the live site before use.
