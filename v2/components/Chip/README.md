# Chip

Chips for topics and filters; status labels for OKR and project state.

`.xd-chip` with a modifier: `--brand` (iris tint) or a V1 family pastel (`--discover`, `--govern`, `--transform`, `--enable`, `--blush`), with `on-pastel` navy text. `.xd-status--good|warning|critical` pairs a square marker with a word; status colour is never used without its label.
