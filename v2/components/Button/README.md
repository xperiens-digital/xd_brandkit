# Button

Pill buttons that lift on hover and squish on press; the spectrum variant grows the V1 conic sweep as an edge that turns while hovered.

Classes: `.xd-btn` (primary, `brand` fill), `--spectrum` (primary plus the turning V1 sweep edge on hover; one per view, for the main call to action), `--secondary` (surface with outline), `--night` (deep blue, for light sections that need weight), `--ghost` (text link style), `--sm` (38px). A trailing `<xd-icon>` nudges right on hover.

Label buttons with a verb and an outcome ("See it working", "Book a discovery"). Never two primaries side by side.
