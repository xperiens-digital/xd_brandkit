# InsightCard

Insights listing card. Its media is the same texture as the article's header (Imagery asset group, `insight-<name>-<n>.webp`), cropped to 16:9 with a slow 4% zoom on hover, so a card and its article always match. Then a topic chip, title and reading time.

Generated textures replace stock photography across the site. The media image is decorative (empty `alt`); the title carries the meaning.
