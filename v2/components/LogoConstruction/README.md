# LogoConstruction

How the lockups are built. Everything is measured in **m**, the size of one pixel cell of the mark (37.5 units in the mark's 424 × 161 drawing; at a 40px mark height, m ≈ 10px).

- **Stacked lockup.** The wordmark is set exactly to the mark's width, 1.5m below the mark's baseline. Its cap height falls out at about 0.74m.
- **Row lockup.** The wordmark's cap height equals 1m and it is centred vertically on the mark's full height. It starts 2.5m after the mark.
- **Clear space.** 1m on every side of any version; nothing else enters it. The grid in the preview shows the module.
- **Minimum sizes.** Mark 16px tall; row lockup 24px tall; stacked lockup 40px mark height; app box 28px.
- **Wordmark.** XPERIENS DIGITAL in Gabarito Bold, +0.12em tracking, outlined to vector paths so it renders identically everywhere. Never retype it in live text.

The V1 lockup set the wordmark at a fixed size beside or under the mark; V2 ties both spacing and size to the module so every lockup is proportionally the same at any size.
