# FormFields

Form controls with a soft `brand-tint` focus halo and springy checks. Wrap each control in `.xd-field` with an `.xd-label`; add `.xd-hint` for help and `.xd-field--error` (plus `aria-invalid`) for validation. Checkbox and radio: `.xd-check > input`; switch: `input.xd-toggle[role=switch]`.
