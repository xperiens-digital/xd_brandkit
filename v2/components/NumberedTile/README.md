# NumberedTile

Numbered boxes for stages, steps and proposal sections. The number is set in **Tiny5** (the pixel face, `font-pixel`), two digits with a leading zero, in iris (`brand`). Use `.xd-pixel-num` for a pixel number anywhere else. Tiny5 is for numbers only; headings stay in Momo Trust Display and labels in the mono eyebrow face. Stage names in this preview are from the approved engagement guide; check copy before client use.
