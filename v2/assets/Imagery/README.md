# Imagery

Generated ambient textures in the V1 palette, owned by X.D. See the Imagery section of the brand book for where each one goes.

- `service-mesh-*.webp`: grain mesh, locked for the five service pages, one colourway per service (800 × 450), plus `service-mesh-hero.webp` (1600 × 900).
- `hero-*.webp`: the six combination textures for general hero banners (1600 × 900).
- `insight-<name>-<1|2|3>.webp`: the same six for Insights headers and cards (1600 × 600); 1 warm, 2 cool, 3 lavender.

All are decorative: use an empty `alt`.
