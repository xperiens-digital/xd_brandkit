# Partners

Vendor and partner marks, carried over unchanged from V1 (Brand Guidelines 1.6). Each file is single colour in V1 subheading grey #5C6B7A.

| File | Partner |
|---|---|
| `microsoft-solutions-partner.svg` | Microsoft Solutions Partner (via Dicker Data) |
| `dicker-data.svg` | Dicker Data, Microsoft distributor |
| `cognitive-view-horizontal.svg` | Cognitive View, responsible AI governance (row lockup) |
| `cognitive-view-stacked.svg` | Cognitive View (stacked lockup) |

Rules: 44px optical height (stacked lockups 88px), at least 48px clear space between marks, single colour only, never recoloured to a brand hue, never animated. On the web use the Partner marks component, which follows the theme (grey on light, light grey on navy). Name partners only where their own materials support the claim.
