HOW THE FILTER IS BUILT

The mp4 itself is untouched. Item 20's treatment is applied as CSS layers on top of it, so the same footage can carry any service gradient and you can retune it without re-exporting video.

  1. Video is desaturated and lifted so it reads as texture, not content.
  2. A flat brand base sits over it, then the four service gradients cross-fade on the 28s / 7s-per-service loop from item 20.
  3. Gradient layers blend in color or soft-light, so the footage keeps its motion but takes the brand hue.
  4. Both grain passes (26s slow, 9s fast) sit on top at overlay, unifying video noise and gradient into one surface.

Use the Tweaks panel to dial blend mode, tint strength and desaturation, then hand the resulting values to the build. For a baked-in mp4, this hero can be screen-recorded or run through ffmpeg with the same values.
